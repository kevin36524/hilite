# HiLite

Bare-bones AI agent for Claude Code CLI users. Runs locally, calls the Anthropic API directly using Claude Code credentials, with a simple tool-calling loop.

## Quick Start

```bash
# One-shot via stdin
echo "What files are in this directory?" | python hilite.py

# One-shot via arg
python hilite.py --prompt "Explain recursion"

# Continue a conversation
python hilite.py --session 20260601-120000-001 --prompt "What was I working on?"

# List saved sessions
python hilite.py --list-sessions
```

## Setup

1. **Install dependencies:**
   ```bash
   pip install anthropic pyyaml
   ```

2. **Authenticate (choose one):**
   - Set `ANTHROPIC_API_KEY` env var
   - Or login with Claude Code: `claude login` (HiLite reads its OAuth token from the macOS keychain)

## Architecture

```
hilite.py              # CLI entry point
hilite/
├── agent/
│   ├── agent.py       # AIAgent class (tool-calling loop)
│   └── anthropic.py   # Auth + Anthropic client
├── tools/
│   ├── registry.py    # Tool schema registry
│   ├── file.py        # read_file, write_file, list_directory
│   ├── shell.py       # execute_command, execute_python
│   └── memory.py      # memory_manage tool
├── skills.py          # Skill discovery and loading
├── skills_auto.py     # Auto-generated skill helpers
├── learning_loop.py   # Closed learning loop (autonomous skill/memory/context)
├── memory.py          # SOUL.md, USER.md, MEMORY.md management
├── state.py           # JSON session persistence
├── config.py          # Env var + file config
└── constants.py       # Paths and defaults
```

## Tools

| Tool | Description |
|------|-------------|
| `read_file` | Read file contents |
| `write_file` | Write content to a file |
| `list_directory` | List directory contents |
| `execute_command` | Run shell commands |
| `execute_python` | Execute Python code |
| `memory_manage` | Read/append to USER.md or MEMORY.md |
| `skill_view` | Load a skill by name |
| `skill_create` | Create a new reusable skill |
| `skill_update` | Update an existing skill |

## Memory

HiLite persists durable facts across sessions in three files under `~/.hilite/`:

| File | Scope | Content |
|------|-------|---------|
| `SOUL.md` | Global | Agent identity and personality |
| `memories/USER.md` | Global | User preferences, habits, background |
| `projects/{key}/memory/MEMORY.md` | Per-project | Project conventions, tools, learnings |

Use the `memory_manage` tool to explicitly save facts, or let the **learning loop** extract them automatically.

## Skills

Skills are reusable markdown files with YAML frontmatter that HiLite can load on demand. They live in:
- `~/.hilite/skills/*.md` — your personal skills
- `./.hilite/skills/*.md` — project-level skills
- `~/.hilite/skills/auto/*.md` — **auto-generated by the learning loop**

Load a skill with `skill_view` or preload it at startup:
```bash
python hilite.py --skill docker-debug "How do I fix this container?"
```

## Learning Loop

HiLite gets better the more you use it through a closed learning loop:

| Feature | Trigger | What it does |
|---------|---------|--------------|
| **Autonomous skill creation** | Conversation uses ≥5 tools | Analyzes the approach and saves a reusable skill to `~/.hilite/skills/auto/` |
| **Self-curating memory** | Conversation runs ≥3 turns | Extracts durable facts and appends them to USER.md or MEMORY.md |
| **Skill improvement** | A skill was used + errors or max turns | Reviews and updates the skill with fixes or clarifications |
| **Context compression** | Messages exceed 30 | Summarizes the middle of long conversations to stay within context limits |

All features are **additive and opt-out** — disable any in `~/.hilite/config.yaml`:

```yaml
learning_loop:
  auto_skills:
    enabled: true
    min_tool_calls: 5
  auto_memory:
    enabled: true
    min_turns: 3
  skill_improvement:
    enabled: true
  context_compression:
    enabled: true
    threshold_messages: 30
```

## Session Storage

Conversations are saved as JSON in `~/.hilite/sessions/`. Each session gets a unique ID (timestamp-based). Use `--session <id>` to continue any conversation.

## Constraints

- **macOS only** — reads Claude Code credentials from macOS keychain
- **Anthropic only** — no other LLM providers
- **Local only** — no messaging, no gateway, no web dashboard
- **Python 3.11+** recommended (3.9+ with `from __future__ import annotations`)
